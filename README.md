# Java Coding Guide Agent Skill 🚀

A comprehensive Java coding guide packaged as an **Agent Skill**. This skill equips AI agents with the expertise to write, refactor, and review Java code according to modern enterprise standards.

---

## 🤖 What is an Agent Skill?

**Agent Skills** are an open standard for giving AI agents (like Claude) new capabilities and domain expertise. They consist of structured folders containing instructions, scripts, and resources that agents can discover and load dynamically to perform specialized tasks more accurately and reliably.

## 📦 About This Skill: `java-coding-guide` ☕

This specific skill provides a robust set of Java backend coding standards, focusing on enterprise-grade development and Spring Boot projects.

### ✨ Key Features
- **Naming Conventions**: Clear rules for interfaces, implementations, and general naming (no prefixes/suffixes like `I` or `Impl`).
- **Javadoc & Comments**: Standardized documentation practices for classes and methods.
- **Modern Java Patterns**: Best practices for Java 8+ features (Stream API, Optional, etc.).
- **Error Handling**: Implementation of the `BusinessException` + `ErrorCode` pattern for clean API responses.
- **Code Quality**: Guidelines on class/method length, complexity, and project structure (DDD).
- **Lombok & Logging**: Best practices for using Lombok and SLF4J logging.

### 🛠️ How to Use
When this skill is active, the agent will:
1. **Adhere** to these standards when generating new Java code.
2. **Review** existing code based on these guidelines.
3. **Refactor** legacy code to match these modern patterns.
